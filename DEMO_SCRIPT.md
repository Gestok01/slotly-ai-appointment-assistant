# Slotly demo video script (under 5 minutes)

## 0:00-0:35 - Problem and solution

Introduce the friction of phone calls and long forms. Explain that Slotly lets a customer book through conversation while giving staff a simple operational view.

## 0:35-2:15 - Customer booking

1. Open Book.
2. Choose a suggested service or type a natural request.
3. Enter the date, time, name, and email.
4. Point out that Slotly asks only for missing information.
5. Review and confirm the booking.
6. Show the unique confirmation reference.

## 2:15-3:25 - Admin management

1. Open Admin.
2. Show the summary counts and new appointment.
3. Change it from confirmed to completed.
4. Explain that both views use the same persistent database.

## 3:25-4:15 - Design and architecture

Show the README system design and data model. Mention Next.js, route handlers, D1, validation, and the fallback that keeps the demo reliable without an API dependency.

## 4:15-4:45 - Edge cases and close

Mention invalid emails, missing fields, status validation, double-submit prevention, and the LLM fallback. Close with the main benefit: faster booking for customers and one workspace for staff.
